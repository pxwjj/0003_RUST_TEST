## 符合类型
### 元组 - tuple `let t: (i32, f64, bool) = (1, 0.2, true);` `t.0`
### 数组 - array `let a: [i32; 5] = [1, 2, 3, 4, 5];` `a[0]`

## 函数 - 参数，需要定义好类型以及变量名称，返回值，只需要写好类型就行，不需要定义出来名称。
### 表达式 - 有返回值 ， 大括号包起来的 块作用域，也是一个表达式，注意，最后一条不要用分号。
### 语句 - 没有返回值
